# Code of conduct

Be respectful and constructive in issues, discussions, reviews, and pull requests. Welcome new contributors and discuss technical disagreements on their merits. Harassment, threats, discrimination, privacy violations, and abuse are not acceptable.

Report concerns privately using the [maintainer contact page](https://sanskarin.github.io/contact/). Maintainers may moderate or remove abusive contributions. This is a project-specific code of conduct and does not imply adoption of an external standard.
