# Rewind64 v0.1.6 — experimental Linux x86-64 prerelease

**Explore execution. Trace every instruction. Understand the past.**

This release strengthens classification of kernel ptrace events for a **single explicitly launched tracee**. It remains experimental; it does not offer reverse execution, execution recording, multi-process following or deterministic replay.

## New since v0.1.5

- Enables Linux `PTRACE_O_TRACEEXEC` and `PTRACE_O_TRACEEXIT`, alongside `PTRACE_O_EXITKILL`.
- Distinguishes synthetic exec/exit ptrace stops via the event number in the upper 16 bits of `waitpid` status, instead of incorrectly treating these kernel-generated SIGTRAP stops as real application signals.
- Resumes event stops with **signal zero**. Application-generated SIGTRAP and ordinary signal-delivery stops are still handled separately.
- Reports `Ptrace exec event: pid=...` and `Ptrace exit event: pid=...`, with `Ptrace events: exec=N exit=N` at termination. These are debugger-observed events, **not** a comprehensive record of process history.
- Includes a new **NASM-only re-exec fixture** (`tests/fixtures/reexec.asm`) that replaces its own image with another authorized Assembly program and checks that it reaches the new program's exit code without a false SIGTRAP.
- Expands Bash integration tests to cover re-exec in standard and compact modes, trace exit-stop counting, and early exit during bounded stepping. No Python dependency added.

## Basic usage

```sh
./rewind64 --version
./rewind64 run --steps 3 /path/to/your/authorized/program
./rewind64 run --changes-only --steps 3 /path/to/your/authorized/program
```

The bounded step count remains 1..64; after stepping, the target continues to termination. Source and test fixtures use NASM Assembly; Bash and Make orchestrate testing and builds.

## Build verification and packaging

The GitHub Actions workflow builds and executes the Python-free native integration tests on Ubuntu 22.04 and Ubuntu 24.04. The prerelease workflow performs a fresh Linux build/test and attaches `rewind64-v0.1.6-linux-x86_64.tar.gz` with `SHA256SUMS.txt`.

## Limitations and security

- Linux x86-64 / glibc / ptrace permissions only. No Windows, macOS, or ARM64 binary.
- One explicitly launched tracee; trace events are observed but the debugger does not follow forked children or multiple threads.
- No interactive debugger, attach, breakpoint manager, memory viewer, tracing-to-file, reverse step, or replay.
- Some Linux ptrace events, complex group stops and advanced signal scenarios are not implemented; event counters are diagnostic, not a complete trace.
- Target executables execute under the invoking user's permissions, not in a sandbox. Inspect only programs you own or are explicitly authorized to debug.
