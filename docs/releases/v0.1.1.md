# Rewind64 v0.1.1 — Linux x86-64 experimental prerelease

**Explore execution. Trace every instruction. Understand the past.**

This is the second **experimental**, Linux-only prerelease of Rewind64. It is **not stable** and does not implement reverse execution.

## Changes since v0.1.0

- New **`run --steps N PROGRAM [ARGS...]`** command option. The default is one instruction; `N` must be a decimal integer from 1 to 64. Register snapshots are printed after each completed step. Early process exit is reported without claiming completion of all requested steps.
- Improved ptrace signal handling: the synthetic single-step `SIGTRAP` is not delivered to the debugged program during normal continuation. Other signal-delivery stops are propagated to the target. A `PTRACE_GETSIGINFO` check distinguishes trace-step traps from program-generated SIGTRAP.
- `waitpid` retries after interruption (`EINTR`).
- Added Assembly test targets for process argument forwarding and a self-generated `SIGUSR1`. Tests also cover program-generated SIGTRAP during stepping and early target exit before the requested step count.
- **Removed all Python source and dependencies from the repository test path.** Tests now run via a Bash test driver against native Assembly fixtures.
- CI now builds from a clean directory and executes the Python-free test suite.

## Verified platform

Linux x86-64 using NASM, libc/glibc, linker, Make, Bash, and coreutils. The release workflow rebuilds and tests on Ubuntu before producing the executable archive and SHA-256 checksum. Source and test code are available at https://github.com/sanskarIN/Rewind64.

## Usage

```sh
./rewind64 --help
./rewind64 --version
./rewind64 run /path/to/your/authorized/program
./rewind64 run --steps 5 /path/to/your/authorized/program arg1
```

`--steps` performs **forward live stepping**, not backward navigation.

## Important limitations

- No attachment, interactive prompt, breakpoints, disassembly, memory explorer, tracing, historical state reconstruction, or replay.
- No Windows, macOS, or ARM64 binary support.
- Only a single launched tracee is managed, with bounded steps. Complex signal, thread, and process-fork scenarios remain incompletely tested.
- System permissions for tracing must allow the launched child process. No permission bypass is provided.
- Debugger errors and target exit codes can overlap.
- Do not debug programs without authorization or assume debugging an untrusted executable is safe.

## Binary and checksum

The prerelease includes `rewind64-v0.1.1-linux-x86_64.tar.gz` and `SHA256SUMS.txt`. Verify the SHA-256 checksum before extracting and running the binary. The archive contains the executable, README, and Boost Software License 1.0.
