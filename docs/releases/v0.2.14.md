# Rewind64 v0.2.14 — experimental Linux x86-64 prerelease

**Explore execution. Trace every instruction. Understand the past.**

This development milestone adds **machine-readable capability discovery** for future IDE, scripting and application integrations. It does not add any new process tracing permissions or a reverse debugger.

## New: `--capabilities`

```sh
./rewind64 --capabilities
```

Prints one JSON document (schema 1) with the program's name, development version, Linux x86-64 platform, ptrace backend, supported execution modes, step limits, read-only inspection limits and explicit unsupported features. It exits 0 without starting a traced program or requiring ptrace permission. Any trailing argument is rejected with exit 2.

```json
{
  "schema": 1,
  "name": "Rewind64",
  "version": "0.2.14-pre",
  "platform": "linux-x86_64",
  "debug_backend": "ptrace",
  "execution": {"modes": ["bounded-step", "observe-only", "interactive"], "max_cli_steps": 64, "max_interactive_step_batch": 16},
  "inspection": {"registers": true, "memory_words_max": 4, "stack_words_max": 4, "rip_bytes_max": 8, "rip_history_max": 16, "signal_history_max": 8, "signal_history_tail": true},
  "limitations": {"single_launched_tracee": true, "forward_only": true, "recording": false, "reverse_execution": false, "replay": false, "breakpoints": false, "attach": false}
}
```

Use the versioned [capabilities contract](../CLI_CAPABILITIES.md) to interpret fields safely. Supported features are build-time declarations, not guarantees that host ptrace policies will permit runtime tracing.

## Tests and release gate

Adds five Python-free Bash integration checks for machine-readable output and strict invocation behavior, optionally validating JSON with `jq` when installed. Expected suite **222 tests** (includes v0.2.13's 13 signal-history tests). Publish **only after** Ubuntu 22.04 and Ubuntu 24.04 integration suites pass, the code is reviewed, and merge is confirmed. The release workflow reruns native `make clean && make test` and packages Linux x86-64 binary, LICENSE, README and SHA256SUMS.

## Experimental scope

Linux x86-64 only; one self-launched tracee. No Windows/macOS backend, attachment, multi-thread tracing, breakpoints, disassembly, persistent trace, deterministic replay, historical CPU/memory restoration or true reverse stepping. No Python code or build dependency. Boost Software License 1.0; trace only programs you have permission to inspect.
