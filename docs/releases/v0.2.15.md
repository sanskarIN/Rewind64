# Rewind64 v0.2.15 — experimental Linux x86-64 prerelease

**Explore execution. Trace every instruction. Understand the past.**

This experimental release makes final interactive stdin commands reliable even when an automation or pipeline ends its last line at EOF **without a trailing newline**. It remains a single self-launched Linux x86-64 tracee debugger, forward-only.

## Exact commands at EOF

A short, exact command such as `status`, `regs`, `history`, `bytes`, `code`, `stack`, `help`, `quit`, `step` or `continue` works as expected whether it is terminated by LF or by EOF. Their supported one-letter aliases work identically. Commands with bounded counts and addresses retain their strict parsing rules. If stdin ends with no command, Rewind64 cleans up the tracee rather than resuming it.

```sh
printf 'status' | ./rewind64 run --interactive ./authorized-program
```

The example is for a target you own or have permission to inspect. `status` reads debugger-owned state and must not forward pending signals or resume the tracee.

- NASM appends one LF and NUL only to a short final input. The existing 64-byte input buffer and overlong-line guard remain unchanged.
- A final newline-terminated input is not rewritten. A full 63-byte command without LF is still rejected and drained, never partially interpreted.
- Recognized `step` or `continue` explicitly resumes execution, as it does when newline-terminated. Read-only commands do not.

## Native regression coverage

Adds **21** Python-free Bash/native NASM integration cases, targeting **243 total**. They verify final no-newline inspection commands and aliases, empty EOF shutdown, SIGILL pending-signal inspection, `step`, `continue`, help, quit and strict rejection of a command-name near miss.

The prerelease workflow requires the complete native suite to pass separately on **Ubuntu 22.04 and Ubuntu 24.04** before its packaging/publish job can start. That job repeats `make clean && make test` before generating the executable archive and `SHA256SUMS.txt`. Publication is conditional on passing all checks. These test totals are planned until CI confirms them.

## Experimental scope

Only Linux x86-64 with a self-launched tracee and host-permitted ptrace. No Windows/macOS backend, disassembly, attaching to arbitrary processes, breakpoints, persistent trace recording, reverse execution, historical CPU/memory restoration, or deterministic replay. No Python. Boost Software License 1.0. This is **not a stable release**.
