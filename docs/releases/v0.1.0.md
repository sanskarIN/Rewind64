# Rewind64 v0.1.0 — Experimental Linux x86-64 prerelease

> **Prerelease:** First native debugger prototype. Not production-ready; no guaranteed source or binary compatibility. The only supported release platform is Linux x86-64.

**Tagline:** Explore execution. Trace every instruction. Understand the past.

## What works
- CLI: `--help`, `--version`, and `run PROGRAM [ARGS...]`.
- Launch a user-selected program under Linux `ptrace`.
- Print two snapshots of RIP, RSP, RAX, RBX, RCX, and RDX: before and after one instruction step.
- Continue execution and report normal exit status and terminating signals.
- Pass program arguments without a shell.
- Attempt to clean up children on errors, and request `PTRACE_O_EXITKILL`.
- Integration tests for exits, a failed executable launch, program-generated SIGTRAP and CLI errors.

## Prerelease limitations
- **No** interactive stepping, attachment to existing processes, breakpoints, memory explorer, execution trace, reverse execution, or deterministic replay.
- One tracee; one instruction step; no tested multithreaded support.
- Linux x86-64 only; requires supported Linux tracing permissions.
- This milestone uses libc APIs from Assembly. Building requires NASM, cc/glibc, ld, and make.
- Some process lifecycle and signal edge cases still require fault-injection and cross-distribution testing.
- Exit statuses are ambiguous when a target deliberately returns a value also used by the debugger.
- Do not debug untrusted or unauthorized executables.

## Install and validate
Download the attached `rewind64-v0.1.0-linux-x86_64.tar.gz`, verify its SHA-256 digest against `SHA256SUMS.txt`, extract, and run `./rewind64 --help`. The archive contains a native executable, the license, and README. It does not run on Windows or macOS.

Build from source: `make && make test` on Linux x86-64 with NASM installed.
