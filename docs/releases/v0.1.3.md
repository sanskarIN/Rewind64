# Rewind64 v0.1.3 — Experimental Linux x86-64 prerelease

**Explore execution. Trace every instruction. Understand the past.**

This **experimental** prerelease adds **live, forward-only register changes** and expands process lifecycle regression testing. It does **not** provide a trace archive, reverse stepping, or deterministic replay.

## What's new since v0.1.2

- Added a native **NASM-only CPU register delta engine** (`src/registers/delta.asm`). After each successfully completed single step, it compares the current 216-byte Linux register snapshot with the immediately preceding snapshot.
- Displays transitions only for changed registers, including the previous/current 64-bit values and total number of changed fields. The 20 compared fields are the 16 x86-64 general-purpose registers (including RSP), RIP, RFLAGS and FS/GS base addresses.
- Leaves the full register snapshot display intact. Snapshots are held in debugger-local memory and **not written to disk**.
- Additional Assembly fixtures verify termination by SIGTERM, signal-delivery handling of a SIGSEGV during stepping, preservation of exit status 255, and the maximum 64-step forward execution limit.
- Extended Bash tests without introducing Python. GitHub Actions tests NASM builds on Ubuntu 22.04 and 24.04.

## Commands

```sh
./rewind64 --help
./rewind64 --version
./rewind64 run /path/to/authorized/program
./rewind64 run --steps 4 /path/to/authorized/program argument1
```

`--steps` accepts integers 1–64, default 1.

## Platform and packaging

- **Supported experimental target:** Linux x86-64 with glibc/Linux ptrace permissions.
- Build: `make clean && make test` with NASM, GNU/ELF linker, Make, Bash, coreutils, and a glibc C toolchain. Python is not required.
- Binary: `rewind64-v0.1.3-linux-x86_64.tar.gz`. Verify it against `SHA256SUMS.txt` from the same release.

## Not yet supported

- Recording and historical state storage, deterministic replay, reverse stepping, breakpoints, attaching to live processes, disassembly, memory browsing, or interactive stepping.
- Windows, macOS, ARM64, multi-threaded and multi-process tracing.
- Full fault-injection coverage and stable debugger error/result separation.

The debugged program runs with your inherited permissions. Only run executables you own or are authorized to inspect; do not treat Rewind64 as an isolation tool.
