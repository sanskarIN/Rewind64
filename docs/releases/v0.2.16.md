# Rewind64 v0.2.16 — experimental Linux x86-64 prerelease

**Explore execution. Trace every instruction. Understand the past.**

This experimental milestone adds an explicit interactive pause at the next **ptrace exec event**. It correctly differentiates the first post-exec synthetic trace trap from genuine INT3 instructions; this does **not** implement breakpoint insertion, cross-process attachment, recording, reverse stepping, replay or multi-tracee event management.

## Interactive `until-exec` / `v`

Run a program you own or have permission to debug:

```sh
./rewind64 run --interactive ./your-authorized-program
```

At the prompt enter `until-exec` or `v`. Rewind64 continues the launched process; any ordinary signal-delivery stops before the next exec are forwarded normally rather than treated as synthetic exec traps. At an actual `PTRACE_EVENT_EXEC`, the debugger pauses at the new executable image and displays a fresh RIP/RSP (and register table unless using `--changes-only`). The next `regs`, `code`, `history`, `status` or `step` command operates on the new image while the tracee is stopped. `history` starts at the new post-exec RIP rather than mixing addresses from unrelated executable images, and preserves the cumulative confirmed step count as its index label.

An exact, EOF-terminated `until-exec` / `v` also works without a trailing newline. `until-exec 1`, case variations and other extra arguments are rejected. If the process exits without reexecing, Rewind64 reports the target's real exit status. `quit` or EOF after a paused exec stops and reaps the launched tracee without forwarding a synthetic signal.

Existing `until-signal`, ordinary `continue`, bounded automatic stepping and signal history remain unchanged. Static `--capabilities` reports `execution.stop_on_exec: true` for the v0.2.16 development executable.

## Validation and packaging

The Python-free native NASM/Bash suite adds **14** targeted exec-stop regressions; **259 total tests are expected**, pending green Ubuntu 22.04 and 24.04 CI. The release job is gated behind both supported Ubuntu test suites, reruns `make clean && make test`, and packages the Linux binary, license, README and `SHA256SUMS.txt`. This document is prepared in advance; publication is not claimed until GitHub reports success and assets exist.

## Limits

Linux x86-64 only; one authorized self-launched tracee; no Python source or build dependency; Boost Software License 1.0. Trace output can contain sensitive register and process information, so share it cautiously. This release is experimental and forward-only, not stable or a reverse debugger.
