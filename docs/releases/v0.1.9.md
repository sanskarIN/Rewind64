# Rewind64 v0.1.9 — experimental Linux x86-64 prerelease

**Explore execution. Trace every instruction. Understand the past.**

This experimental release adds an **observation-only** workflow for one explicitly launched program. This is **not** an interactive debugger, execution recorder, reverse debugger or sandbox.

## What's new

- New `run --observe-only [--changes-only] [--] PROGRAM [ARGS...]` command option. Rewind64 captures the **initial Linux x86-64 CPU register snapshot** at the initial traced exec stop, then calls `PTRACE_CONT` and observes delivered signals, exec events and exit events until the tracee terminates. It issues **zero** `PTRACE_SINGLESTEP` requests. The end-of-run diagnostic reports `Steps completed: 0 / 0`.
- `--observe-only` is **mutually exclusive** with `--steps N` in both flag orders. Repeated `--observe-only` is rejected, while `--changes-only` and the explicit `--` delimiter remain supported.
- For verified user-originated Linux signals (`siginfo_t.si_code == SI_USER` or `SI_TKILL`), display the sender's PID and UID using the `siginfo_t` kill-layout fields. Do **not** interpret those union fields as a sender for kernel-generated faults such as SIGSEGV/SIGILL/SIGFPE.
- New Python-free Bash integration cases cover observation mode with normal exits, `exit_group`, in-process `execve`, repeated handled signals, fatal signals, unsupported group stops, compact register display, target argument forwarding and incompatible options.
- The existing default `run PROGRAM` behavior retains one bounded initial forward step, and `--steps N` remains limited to 1..64.

## Examples

```sh
./rewind64 --version
./rewind64 run --observe-only /path/to/authorized/program
./rewind64 run --observe-only --changes-only /path/to/authorized/program arg1
./rewind64 run --steps 4 --changes-only /path/to/authorized/program
```

With `--observe-only`, no per-instruction register deltas are emitted because no instructions are single-stepped. The initial full snapshot remains available unless `--changes-only` is requested.

## Build and package

- **Platform:** Linux x86-64, glibc/ptrace permissions.
- **Sources:** native NASM x86-64 Assembly, plus Make/Bash test orchestration. Python is not required.
- **Tests:** `make clean && make test` on Ubuntu 22.04 and Ubuntu 24.04 GitHub Actions runners.
- **Release assets:** `rewind64-v0.1.9-linux-x86_64.tar.gz` with matching `SHA256SUMS.txt`. Verify the downloaded archive against its checksum.

## Limitations

One tracee only, with no attach, multiple-thread/fork following, interactive console, breakpoints, memory explorer, trace-file persistence, historical navigation, reverse execution, deterministic replay, or Windows/macOS/ARM64 backend. Some job-control group stops are detected as unsupported and lead to tracee cleanup. Linux kernel policies may prevent ptrace. Target programs run with the invoking user's privileges, **not in a sandbox**. Only debug programs you own or are authorized to inspect.
