# Rewind64 v0.1.8 — Linux x86-64 experimental prerelease

**Explore execution. Trace every instruction. Understand the past.**

This experimental prerelease expands low-level process-state diagnostics. Rewind64 remains a **single-tracee, forward-only** Linux debugger prototype, without recording, replay, or interactive controls.

## Changes since v0.1.7

- Uses Linux `PTRACE_GETEVENTMSG` at a synthetic `PTRACE_EVENT_EXIT` stop to retrieve and display the kernel-supplied raw exit wait status as `Ptrace exit detail: raw_wait=0x........`. This is an event-time diagnostic, not the final result of `waitpid`, and should not be interpreted as execution history.
- Reports the **signed `siginfo_t.si_code`** for valid signal-delivery stops. For example, `SI_USER` (usually `0`) and `SI_TKILL` (usually `-6`) can now be distinguished in `Signal-delivery stop: signal N si_code=C` output. Exact codes are Linux ABI-specific.
- Adds native NASM test fixtures `tests/fixtures/thread_signal.asm` (self-directed `tgkill`) and `tests/fixtures/exit_group.asm` (Linux `exit_group` status 23).
- Expands the Python-free Bash integration suite to check both full and concise output, signed signal source codes, and expected raw wait-status values for successful exits, `exit_group`, and an in-process `execve`.
- Keeps the existing bounded cleanup behavior from v0.1.7, the Boost Software License 1.0, and Linux x86-64 only compatibility.

## Commands

```sh
./rewind64 --help
./rewind64 --version
./rewind64 run --steps 3 /path/to/an/authorized/program
./rewind64 run --changes-only --steps 3 /path/to/an/authorized/program
```

The default step count is 1, and explicit `--steps` accepts 1–64. Rewind64 will continue the target after bounded stepping and report its termination status.

## Build, test and verify

- Native NASM, Linux/glibc, GNU ELF linker and compiler toolchain, Make and Bash; **Python is not used or required**.
- Run `make clean && make test`. The release pipeline rebuilds and tests on Linux and publishes `rewind64-v0.1.8-linux-x86_64.tar.gz` together with `SHA256SUMS.txt`.
- GitHub Actions validates the native test suite on Ubuntu 22.04 and 24.04.

## Boundaries

This release does **not** add Windows/macOS/ARM64 binaries, process attachment, interactive debugging, multithread tracing, trace file persistence, memory browsing, breakpoints, reverse execution or deterministic replay. Unusual signal/event sequences and pathological cleanup remain areas for further testing.

Target executables run with the invoking user's environment and permissions; Rewind64 is not a sandbox. Only inspect programs you own or have explicit authorization to debug.
